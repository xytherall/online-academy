# Online Academy

Website and portal for an online O Level / A Level academy — public site, student portal, and admin area.

See [`docs/SPEC.md`](docs/SPEC.md) for the full specification (source of truth) and [`CLAUDE.md`](CLAUDE.md) for how this repo is worked on.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `.env.example` to `.env.local` and fill in your Supabase project's URL and keys before running the app.

## Commands

```bash
npm run dev         # start dev server
npm run lint        # lint
npm run typecheck   # TypeScript check
npm run build       # production build
```
